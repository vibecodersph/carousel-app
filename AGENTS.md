# Repository workflow

## AI Brief JP source recommendations

For requests to find, recommend, rank or shortlist source videos for AI Brief JP
reels, follow `docs/SOURCE_RECOMMENDATIONS.md`. Read the latest Moneyball source
feedback, including underperformers and recommendation misses, before selecting
sources. Record the outcome-grounded shortlist with
`scripts/source_recommendations.py recommend` before presenting it. Preserve
exact source IDs, source/speaker distinctions, modes, timestamps and rationales.
Respect explicit user choices and existing publishing permissions.

This requirement is scoped to source recommendations; it does not require a
source search for ordinary code edits, analytics questions or user-selected
video production. Never infer historical recommendation dates or fabricate
prospective records for already-published reels.

For the authorized continuous AI Brief loop, follow
`ops/codex-aibrief-jp-continuous-loop.md`. Learning-managed production needs a
prospective clip plan and sealed media binding before scheduling. Existing
user-selected assets and fixed-pool Trial workflows retain their own scope.
